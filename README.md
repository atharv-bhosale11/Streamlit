# Streamlit – Python Web Applications

This repository is dedicated to learning and exploring **Streamlit**, a Python framework for building interactive web applications. It will cover fundamental concepts, UI components, user interactions, data visualization, and AI-powered applications.

## 🎯 Learning Objectives

- Understanding Streamlit fundamentals.
- Building interactive web applications using Python.
- Working with widgets, buttons, forms and user inputs.
- Handling file uploads and document processing.
- Creating interactive data visualizations and dashboards.
- Integrating Machine Learning, Deep Learning and Generative AI models into web applications.

## 🛠️ Technologies

- **Programming Language:** Python
- **Framework:** Streamlit
- **Tools:** VS Code, Git, GitHub

## 📚 Topics Covered

- Streamlit Basics
- UI Components & Widgets
- User Input & Interactions
- File Handling
- Data Visualization
- Interactive Dashboards
- Machine Learning Applications
- Deep Learning Applications
- Generative AI Applications
